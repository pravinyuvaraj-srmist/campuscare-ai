# Demo Script

## 1. Problem
"Students often need help locating the right campus service or procedure, especially when the information is spread across different places."

## 2. Solution
"CampusCare AI provides a single conversational entry point and grounds answers in a curated knowledge base."

## 3. Live flow
1. Open the web app.
2. Ask: "I lost my student ID. What should I do?"
3. Show the generated guidance.
4. Show the source section.
5. Ask a second question about hostel or medical support.
6. Explain that the next iteration will replace the starter retrieval layer with embeddings/vector search and a production LLM.

## 4. Important limitation
"The current hackathon MVP demonstrates the complete architecture using a small local knowledge base. Production deployment would require verified institutional sources, stronger retrieval, authentication, monitoring, and privacy controls."
